مكتبة محمود يسري العزب — نسخة أولية جديدة

الملفات:
- index.html الصفحة الرئيسية
- reader.html قارئ الكتاب
- about.html عن الكاتب
- rights.html حقوق الملكية الفكرية
- contact.html التواصل
- style.css التصميم
- books/ ملف PDF للكتاب الأول

طريقة النشر:
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages، مع الحفاظ على بنية مجلد books.
لا تحذف النسخة المنشورة قبل تجهيز نسخة احتياطية والتأكد من الملفات.

ملاحظة مهمة بشأن الحقوق والحماية:
واجهة القراءة لا تعرض زر تنزيل وتستخدم PDF.js لعرض الصفحات. لكن لأن الموقع عام والملف يجب أن يصل إلى متصفح القارئ، فلا يمكن ضمان منع تنزيله أو استخراجه تقنيًا بنسبة 100%. للحماية الأقوى يلزم نظام قراءة خلف تسجيل دخول وخادم يتحكم في الوصول أو DRM.

الكتاب المرفق هو الكتاب الذي أرسله المستخدم في هذه المحادثة. بقية الكتب تضاف بعد استلام ملفاتها.
